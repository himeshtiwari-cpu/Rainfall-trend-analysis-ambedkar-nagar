# Rainfall-trend-analysis-ambedkar-nagar
# Project Overview- This project was completed as part of my B.Tech in Agricultural Engineering. It focuses on rainfall trends in Ambedkar Nagar district, Uttar Pradesh, and the morphometric characteristics of the Maharuwa micro-watershed.
# Objectives- 1.To analyze rainfall trends in Ambedkar Nagar district. 2.To study the morphometric characteristics of the Maharuwa micro-watershed.
